# Marca NexoMx

## Logo

La N son dos columnas, dos plantas o dos empresas, unidas por un eslabón: el nexo.

| Archivo | Uso |
| --- | --- |
| `public/nexomx-logo.svg`, `brand/nexomx-logo.png` | Sobre fondos claros |
| `public/nexomx-logo-oscuro.svg`, `brand/nexomx-logo-oscuro.png` | Sobre fondos oscuros |
| `public/nexomx-simbolo.svg`, `brand/nexomx-simbolo.png` | Solo el símbolo, para perfiles y espacios cuadrados |
| `public/favicon.svg`, `brand/nexomx-app-icon.png` | Ícono de pestaña y de aplicación |

Los SVG tienen el texto convertido a trazos: se ven igual sin instalar la tipografía.

## Colores

Salen de materiales de México.

| Nombre | Hex | Uso |
| --- | --- | --- |
| Obsidiana | `#101917` | Texto y marco de la aplicación |
| Jade | `#0B6E5B` | Color de marca, botones y datos |
| Jade claro | `#5CC9B0` | Jade sobre fondo oscuro |
| Cempasúchil | `#E8930C` | Eslabón del logo, favoritos y alertas de consumo |
| Cantera | `#E7ECEA` | Superficies secundarias y pistas |
| Papel | `#FFFFFF` | Área de trabajo |

Escala de jade para el mapa: `#D3EEE5`, `#9FD9C7`, `#56BFA3`, `#11806A`, `#053D32`.

Los tokens de la interfaz están en `src/index.css`.

## Tipografía

IBM Plex Sans en toda la marca. IBM Plex Mono solo para contraseñas generadas.
